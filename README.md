# 早早大王早起成长营

主打真人励志 IP 陪伴式自律打卡训练营。以「早早大王」从辍学打工一路读到博士的逆袭故事做核心，围绕早起打卡、视频监督、分档会员社群与履约激励，帮助普通人建立自律系统。

核心 Slogan：**普通人也能逆天改命，往后你的人生有千千万万种可能。**

## 技术说明

- 纯静态 Web 应用，零构建、零依赖，`index.html` + `styles.css` + `app.js`。
- 数据通过浏览器 `localStorage` 本地持久化，开箱即用。
- 移动端优先，同时适配桌面端。

## 本地运行

```bash
python3 -m http.server 8137
```

然后访问 `http://127.0.0.1:8137/`。

## 功能模块

1. 首页：IP 展示、快捷入口、排行榜、晨间监督房、成功案例墙、每日一句
2. 打卡计划：多周期目标、模板库、打卡日历、统计报表、备注标签、复盘
3. 社群：分会员等级社群、群打卡面板、群公告、排行榜、豁免申请
4. 视频监督房间：会员白名单、静音专注、番茄钟、公开房 / 小房间
5. 会员中心：周/月/季/年卡、履约规则、订单记录、履约奖励
6. 个人中心：勋章、电子证书、数据看板、心愿墙、复盘、身体记录
7. 发现广场：打卡动态、话题广场、干货专区、分享海报
8. 消息通知：打卡提醒、社群消息、履约提醒、周报

以及番茄钟、晨间电台、自律契约书、情绪树洞、组队打卡、月度复盘问卷等增值功能。
